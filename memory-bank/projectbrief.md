# Meeplit 项目概览

## 项目定位
Meeplit 是一个多人回合制卡牌游戏框架，旨在让开发者免于网络通信和数据同步的困扰，以最简单的方式编写游戏逻辑。

## 核心理念
**反向 RPC**：传统的通信模式是客户端请求服务器，服务器返回结果。Meeplit 采用相反的模式——服务器主动询问客户端“这回合你要做什么”，客户端返回结果由服务器处理。这样，游戏逻辑可以集中在一个 main 函数中完成，大大简化了联机棋牌游戏的开发复杂度。

## 设计哲学

### "能玩就行"
1. **画面简陋没关系**：使用固定几个动画，只要玩家能看明白发生了什么就行
2. **延迟大没关系**：桌游的网络延迟可以淹没在玩家的思考过程中
3. **核心目标**：让开发者专注于游戏逻辑，而不是网络通信细节

### 开发原则
- 游戏逻辑集中在服务器的一个 main 函数中
- 客户端只负责展示和收集玩家输入
- 共享类型必须放在 `packages/shared`
- 游戏局内通信遵循“服务器询问客户端”模式

## 当前状态
项目处于**抽空开发中**状态，核心框架已基本完成，但游戏逻辑和 UI 组件仍在完善中。

## 项目愿景
为桌游开发者提供一个极简的联机框架，让编写多人卡牌游戏像写单机游戏一样简单。
